# Student Task Manager

A responsive web application that helps students manage daily academic tasks, track completion, organize priorities, and monitor attendance in one place.

## 🚀 Live Demo
[**Open Student Task Manager**](https://surendrabeniwal85.github.io/student-task-manager/)

## ✨ Features
- Student registration and login
- Create, edit, and delete tasks
- Set task priorities and due dates
- Mark tasks as completed
- Filter and organize tasks
- Track subjects and attendance
- Responsive user interface

## 🛠️ Tech Stack
- HTML5
- CSS3
- JavaScript

## ▶️ Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/surendrabeniwal85/student-task-manager.git
   ```
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
